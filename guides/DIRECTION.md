# Direction — shot grammar
1. **A shot starts on the word** it illustrates (`at='आठ'`). Never on a timestamp except the first shot of a beat.
2. **3–4 s per shot** (QA: avg 2.6–4.2, max 6.5). If a beat is long, cut on each clause.
3. **Alternate scale**: wide establishing → medium two-shot → close-up → insert/icon. Never two identical frames in a row.
4. **Names** → all named characters in ONE frame with name pills (y≈ above heads), appearing on their cue word.
5. **Symmetry**: groups are centered around x=640; two-shots at x=640±330; four at ±100/±300.
6. **Events on words**: effects use `cues=[…]` so the flash/shock/icon lands exactly on the word.
7. **Constant motion**: every shot has a camera move (rotating CAMS), parallax clouds, dust/embers; use `shake` on rage/impact.
8. **Emotion → grade**: calm=cel/warm, wonder=warm, dread=night/void, rage=red+embers, sorrow=dark, hope=dawn/warm.
9. **Close-ups** use figure upper body at s≈2.7–3.4 (y≈900–985) so crowns/heads are never clipped.
10. Dissolve (`dx`) only between scene changes (default 0.28 s); hard cut for impact.
