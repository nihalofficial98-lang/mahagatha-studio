# Reel style (from the owner's sample reels: King Shibi, Lakshmana's sleep, Yudhishthir and the Yaksha)
- 140-180 words, ~60-75 s. One story, one idea.
- Line 1 = the most shocking or surprising fact (context at once). Or a popular claim snapped back: "<claim>. Well, not really." (contrarian snapback, see .claude/skills/triple-hook).
- Name the source early; give exact location only if the source file has it. Never invent verse numbers.
- Short plain past-tense sentences, one action each, mostly indirect speech; no filler, no decoration, no moral lecture.
- Build step by step (demand -> compliance -> bigger demand; or claim -> source -> origin of the myth).
- Ending in the last 2-3 sentences, one of: twist/reveal, respect restored after a myth is corrected, or one open question that invites comments. Story is complete in every case.
- Each reel is self-contained: re-introduce every name; no "as we saw".
