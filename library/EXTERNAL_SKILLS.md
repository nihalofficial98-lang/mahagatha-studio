# External skills added to this repo (reference only; the engine is NOT changed)
Installed under .claude/skills/ (copied from the owner's links; licenses in the source repos):
- cloudai-x/threejs-skills (13 skills, three.js r186): threejs-fundamentals, -geometry, -materials, -lighting, -textures, -shaders, -animation, -postprocessing, -loaders, -interaction, -performance, -asset-pipeline, -react-three-fiber.
- iart-ai/javascript-animation-skills: javascript-animation (frame-pure code-drawn canvas films), soundtrack (code-made music/SFX).
- iart-ai/explainer-video-skills: explainer-video, diagram-animation, whiteboard-animation, isometric-animation, wrapped-video.
More packs: https://github.com/iart-ai/motion-skills (index of 19 pack repos).

Where to use them (as references, never as a replacement of the paper-cut engine):
- effects-designer / scene-designer: ideas and craft rules from javascript-animation (easing, timing, deliver-and-verify frames).
- sound-director: soundtrack skill for code-made music/SFX ideas (our renderer is episodes/ep06/sound/render_sound.py).
- explainer format (guides/LONG_STYLE.md): explainer-video + diagram-animation for map/diagram/number-scale shots (e.g. Varaha size comparisons), drawn in our own canvas style.
- threejs-*: only if a future episode asks for a 3D shot or background; not part of the standard flow.
